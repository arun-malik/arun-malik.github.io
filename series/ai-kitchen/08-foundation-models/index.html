Our timing model has one narrow job. A recipe assistant might summarize a note, explain a term, and draft a menu. It is usually built on a model that had broad training before meeting our cafe.

A reusable starting point

A foundation model is a model trained on broad data that can be adapted to many downstream tasks. Think of a general kitchen base that can contribute to several dishes, though the model's reusable material is learned parameters rather than food.

A large language model, or LLM, is a large model trained to model language patterns. Many widely used LLMs generate text, but language-model training can also support representations and other tasks. “Large” has no single permanent size cutoff that settles whether a model will be useful.

A generative model produces content, such as text, an image, or audio. A predictive model may instead output a category or quantity. The boundary is about the task and output, not two unrelated sciences: generating text can involve repeatedly predicting the next token.

Practice before the cafe opens

Pretraining is an initial broad training stage before later adaptation. Self-supervised learning creates training targets from the data itself instead of requiring a person to label each target.

For next-token training, a sentence supplies its own practice questions. Given the earlier tokens, predict the next recorded token. For masked-token training, predict a hidden piece using the permitted surrounding input. The learning procedure calculates loss and adjusts weights across many such examples.

The machine is not handed a clean list of verified facts. Its parameters capture learned regularities, and training can also lead to memorization. Pretrained knowledge is not a guaranteed-current database with a correct row for every question.

Teach a particular way of responding

Fine-tuning is additional training that adapts a pretrained model using more data. Some methods update all weights; others adjust only a subset or added parameters. Either way, this is a training change.

Instruction tuning trains on examples of requests and desired responses to improve instruction following. Imagine practicing the difference between reciting a recipe and answering a customer's specific question about it.

Preference alignment adapts behavior toward preferences expressed in training feedback. People might prefer a clear, relevant explanation over a confusing answer to the same request. Preferences reflect the criteria and people supplying them; they are not a universal definition of truth.

RLHF means reinforcement learning from human feedback. In a common approach, human comparisons train a reward model, then reinforcement learning adjusts the language model toward that reward. Optimizing the learned reward can still miss what people intended.

Direct preference optimization, or DPO, trains directly on preferred and less-preferred response pairs with a preference objective relative to a reference model. It avoids the separate reward-model-and-reinforcement-learning loop used in that common RLHF setup. It is not proof that the chosen answer is correct or safe.

These are possible adaptation methods, not mandatory steps every model follows in this exact order.

Beyond text

A modality is a kind of information, such as text, images, or audio. A multimodal model handles more than one modality. It might accept a menu photograph and a typed question. Accepting images does not imply it can generate images, and a photo does not expose every hidden ingredient.

Diffusion is a family of generative methods that learns to reverse a gradual noising process. In a common image-generation setup, training teaches denoising at different noise levels; generation starts with noise and repeatedly refines it, possibly guided by a text prompt.

The drawing is an invented visual intuition for refinement, not an actual model output. Some systems work in compressed representations rather than pixels. Not every image or audio model uses diffusion, and not every generative model works by selecting the next text token.

We paste a new recipe into a chat. Did we fine-tune the model?

No. Supplying a recipe for the current interaction changes available context. Fine-tuning requires an actual training process that changes learned parameters.
