What the recipe becomes

The reusable recipe becomes executable, inspectable software.

01
Check coverage

Use the recipe only when it supports the requested drink and modifiers.

02
Bind the parameters

Map oat milk, extra-hot temperature, and syrup into the reusable workflow.

03
Execute and verify

Run the machine, check the result, and recover explicitly when verification fails.

turmeric-latte.ts explicit · inspectable · testable
function makeTurmericLatte(order, machine) { if (!recipe.supports(order)) return agent.investigate(order); const parameters = recipe.bind(order); const result = machine.execute( recipe.steps, parameters); return recipe.verify(result) ? result : recipe.recover(result); }
